Novel Desk

GitHub で作った fine-grained トークンを入れてください（作品のリポジトリだけ、Contents の読み書きと Metadata の読み）。トークンはこの端末の中に暗号化して置き、GitHub の API にだけ送ります。

GitHub でトークンを作る

開いた画面で、Repository access の「Only select repositories」から作品のリポジトリを選び、Generate token を押して、出たトークンを下に貼ってください（名前、期限、Contents の読み書きは入れてあります）。

先にホーム画面に追加してください

Safari のタブとホーム画面のアプリでは、この端末の保存場所が別になります。ここでトークンを入れても、ホーム画面のアプリからは見えません。ホーム画面に追加してから、そこから開いてトークンを入れてください。

  1. 画面の下（iPad では上）の共有ボタン（四角から矢印が出ている形）を押す
  2. 「ホーム画面に追加」を押し、「追加」を押す
  3. ホーム画面の Novel Desk から開く

この端末にアプリとして入れると、ホーム画面やアプリの一覧から開けます。
