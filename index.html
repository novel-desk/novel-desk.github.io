トークンで始める

GitHub で作った fine-grained トークンを入れてください（作品のリポジトリだけ、Contents の読み書きと Metadata の読み）。トークンはこの端末の中に暗号化して置き、GitHub の API にだけ送ります。

GitHub でトークンを作る

開いた画面で、Repository access の「Only select repositories」から作品のリポジトリを選び、Generate token を押して、出たトークンを下に貼ってください（名前、期限、Contents の読み書きは入れてあります）。

GitHub で選んだ期限の日です（「GitHub でトークンを作る」で作ったなら 90 日後）。期限なしのトークンなら空にしてください。GitHub はアプリにトークンの期限を教えないので、ここで覚えておき、切れる 14 日前から知らせます。

新しい作品

GitHub に非公開のリポジトリを作り、題名を入れた novel.toml、README.md、最初の話を置きます。中身のない（空の）リポジトリは、「GitHub リポジトリをインポート」から開くと作品として始められます。

リポジトリを作るには、いつものトークン（Contents だけ）とは別に、Repository access を All repositories にし、Repository permissions の Administration を Read and write にしたトークンが要ります。いつものトークンには付けないでください。このトークンは作るときだけ使い、この端末には残しません（期限を短くして作り、使い終わったら GitHub で消してください）。いつものトークンで作ったリポジトリを読めないときは、いつものトークンの Repository access にそのリポジトリを足してください。
リポジトリの名前を変更

名前を変えるには、いつものトークン（Contents だけ）とは別に、このリポジトリの Repository permissions の Administration を Read and write にしたトークンが要ります。いつものトークンには付けないでください。このトークンは名前を変えるときだけ使い、この端末には残しません。GitHub は古い名前を新しい名前へ送るので、いつものトークンはそのまま使えます。
